# Jac

**One language for AI-native full-stack development.**

Jac supersets Python and JavaScript with native AI constructs, graph-based data modeling, and full-stack capabilities. Write backend, frontend, and AI logic in a single language with access to the entire PyPI and npm ecosystems.

```bash
pip install jaseci
```
